# Project Rules for Toopai.ai

- **Jangan pernah melakukan git commit atau git push secara otomatis** tanpa perintah atau persetujuan tertulis secara langsung dari USER.
- Setiap kali selesai melakukan perubahan file, laporkan perubahan tersebut kepada USER dan tunggu instruksi selanjutnya.
- Jika USER meminta melakukan commit, langsung jalankan git commit menggunakan pesan commit bahasa Inggris yang merinci seluruh perubahan file yang dilakukan.
